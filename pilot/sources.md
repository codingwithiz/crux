# AI / GenAI Source Shortlist (primary-first)

The principle: **a few primary sources beat a big feed.** Read the actual thing (paper, changelog, repo) before any commentary. Pick **one** item/day from here.

## Primary — start here ("what actually happened")
1. **Hugging Face Daily Papers** — curated & ranked daily — https://huggingface.co/papers
2. **arXiv** (recent submissions):
   - cs.CL (NLP) — https://arxiv.org/list/cs.CL/recent
   - cs.LG (ML) — https://arxiv.org/list/cs.LG/recent
   - cs.AI — https://arxiv.org/list/cs.AI/recent
3. **AI lab blogs / changelogs** (the source, not the recap):
   - OpenAI — https://openai.com/news/
   - Anthropic — https://www.anthropic.com/news
   - Google DeepMind — https://deepmind.google/discover/blog/
   - Meta AI — https://ai.meta.com/blog/
   - Mistral — https://mistral.ai/news/
4. **Hacker News** (top AI stories) — https://hn.algolia.com/?query=AI&sort=byPopularity&type=story
5. **GitHub Trending** (overall / Python, daily) — https://github.com/trending
6. **Hugging Face — trending models** — https://huggingface.co/models?sort=trending

## Secondary — cross-check / find the debate (NOT your primary read)
Use these to see *what others argue*, then form your **own** variant view:
- Import AI (Jack Clark) · The Batch (DeepLearning.AI) · Latent Space (swyx) · Ben's Bites

## Discipline
- **One item per day.** Skim ten and you'll think about none.
- Prefer the **primary source** over the thread about the primary source.
- If nothing today is genuinely worth an opinion, log **"no item."** That's an honest, valid outcome — manufactured takes are slop.
